# TPTAF

Task-Prior Tripartite Attention for Infrared and Visible Image Fusion

This repository is the official project page for the TPTAF paper. The manuscript is currently under review, so this repository only provides a project placeholder and a release plan. The complete implementation, trained models, configuration files, and usage instructions will be released progressively after acceptance.

## Repository Status

- The paper is under review.
- No source code or trained model weights are released at this stage.
- The current files are used only to organize the future reproducibility materials.
- The full release will be prepared after acceptance.

## Planned Release

After acceptance, we plan to provide:

- source code;
- model checkpoints;
- configuration files;
- data preparation instructions;
- training and testing instructions.
